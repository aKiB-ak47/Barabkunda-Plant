Mobile app

The Barabkunda app

Everything on this site in an app on your phone: the red flags, both reports, the TPM programme and the equipment guide. It opens the latest data each time and keeps a copy for when there is no signal.

Android

Download and install the app file directly; no app store needed.

Download for Android ↓APK · {{apk_size}} · version {{apk_ver}} · Android 7 or newer
  1. Tap Download for Android and open the file.
  2. If asked, allow your browser to install unknown apps.
  3. Tap Install, then open Barabkunda.

iPhone and iPad

Add the app to your home screen from Safari; it opens full screen, like any other app.

  1. Open this page in Safari.
  2. Tap Share (the square with an arrow).
  3. Choose Add to Home Screen, then Add.

Computer

Install it as an app in Chrome or Edge: it gets its own window and a desktop icon.

  1. Open this page in Chrome or Edge.
  2. Select the install icon at the right of the address bar.
  3. Choose Install.
